# 地图数据编辑器 · 使用手册

> 适用对象：需要修改校园室内导航地图数据的老师和同学
> 配套文档：[开发文档](DEV.md)（面向开发者，普通用户无需阅读）

---

## 1. 这是什么

**地图数据编辑器**是一个离线的可视化工具，用来查看和修改校园导航所用的地图数据（房间、道路、楼梯、电梯、地点等）。它以图形化方式展示地图，改完后可导出数据文件，更新到导航应用中。

- **不用安装任何软件**，双击一个文件即可使用
- **完全离线运行**，不需要联网
- 所有修改都**可以撤销**

---

## 2. 启动方式

### 2.1 前提条件

- 一台电脑（Windows / macOS / Linux 均可）
- 一款现代浏览器：Chrome、Edge、Firefox 或 Safari（近两年内的版本）

不需要安装 Python、Node.js 或任何其他软件。

### 2.2 启动步骤

1. 打开项目中的 `tools` 文件夹
2. **双击 `map-editor.html`** 文件，它会在浏览器中打开
3. 看到"地图数据可视化编辑器"字样即启动成功

### 2.3 载入地图数据

两种方式任选其一：

- 点击左上角 **「导入数据」** 按钮，选择 `data/map-data.json` 文件；
- 或者直接把 `map-data.json` 文件**拖进浏览器窗口**。

载入后，默认显示 L1 楼（地面层）的平面图。

## 4. 基本操作

### 4.1 浏览地图

| 操作 | 方法 |
|---|---|
| 平移地图 | 在画布上按住鼠标左键拖动 |
| 缩放 | 鼠标滚轮（以鼠标位置为中心缩放） |
| 适配全图 | 点击工具栏「适配」 |
| 回到中心 | 点击工具栏「原点」 |
| 切换楼层 | 点击底部楼层栏的楼层按钮（如 L1、L2） |
| 参考其他楼层 | 勾选工具栏「参考其他层」，可以半透明看到其他楼层的轮廓作对照 |

### 4.2 选择对象

| 操作 | 方法 |
|---|---|
| 选择单个对象 | 左键单击节点 / 边 / 兴趣点 / 标签 / 多边形 |
| 多选节点 | 按住 **Shift** 键逐个点击节点 |
| 框选节点 | 按住 **Shift** 键在空白处拖出方框 |
| 取消选择 | 点击空白处，或按 **Esc** 键 |

选中后，右侧属性面板会显示它的详细信息，可以修改。

### 4.3 搜索

在工具栏的搜索框输入名称（如 `D202`、`食堂`、`南门`），下拉列表会显示匹配的兴趣点、节点和标签，**点击结果可直接跳转**到该位置并选中。

### 4.4 图层控制

点击工具栏「图层」，可以分别显示 / 隐藏：**多边形、标签、节点、边、兴趣点、网格**。数据多的时候，关掉部分图层会更清晰。

## 5. 编辑功能

先在工具栏的下拉框中选择工具，再在画布上操作。**改错了随时可以点「撤销」。**

### 5.1 选择 / 拖拽（默认工具）

- **拖动节点**：修正路网位置。标签和兴趣点会跟着节点一起移动；相关步行路段的长度会自动重算。
- **拖动多边形**：整体平移房间、区域轮廓。
- **编辑多边形顶点**（选中多边形后）：
  - 拖动**方形小点**（顶点）→ 移动顶点
  - 点击**圆形小点**（边中点）→ 在该处插入新顶点
  - 选中顶点后按 **Delete** 键 → 删除顶点（至少保留 3 个）
- **修改属性**：在右侧属性面板直接改文字、数字或下拉选项，改完按回车或点击别处生效。

### 5.2 新增节点

1. 工具栏选择「新增节点」
2. 在画布上点击落点（开了"吸附网格"会自动对齐格点）
3. 在右侧属性面板填写名称、类型编码、楼栋等

### 5.3 连线（新增道路段）

1. 工具栏选择「连线（点两个节点）」，并先选好边类型（**步行 / 楼梯 / 电梯 / 入口**）
2. 依次点击**两个节点**
3. 两点之间自动生成路段，默认长度按实际距离计算

### 5.4 新增兴趣点

1. 工具栏选择「新增兴趣点」
2. 在画布上点击落点（自动关联最近的节点）
3. 在属性面板填写名称、类型（教室 / 楼梯 / 电梯 / 卫生间等）、楼栋

### 5.5 绘制多边形（画房间、区域）

1. 工具栏选择「绘制多边形」，并在旁边的下拉框选好区域类型（房间 / 楼梯 / 草地…）
2. 沿区域轮廓**逐点点击**；
3. **双击**或按 **Enter** 键闭合图形（至少 3 个点）；按 **Esc** 取消。

### 5.6 新增标签

- 选择「新增标签」工具后在画布上点击；或
- 选中某个节点 / 多边形后，点击属性面板中的「为选中实体添加标签」。

### 5.7 删除对象

1. 选中要删除的对象（可多选节点）
2. 按 **Delete** 键或点击工具栏「删除」
3. 在弹出的确认框中核对影响范围后确认

> 删除节点时，若它还连着路段，需要勾选「同时删除关联边」才能继续——这是防止误删造成数据悬空的保护机制。

### 5.8 楼层管理

底部楼层栏右侧有三个按钮：

- **＋层**：新增楼层（填写编号如 L16、垂直层级）
- **－层**：删除当前楼层（会连带删除层内全部数据，可撤销）
- **层属性**：修改楼层编号、名称、备注、垂直层级、室内 / 室外

楼层按钮上的 **▲ / ▼** 可调整楼层的显示顺序。

## 6. 联动机制（重要）

地图数据里，同一个地点有多份"影子"信息（路网节点、文字标签、兴趣点、房间轮廓）。编辑器会自动保持它们一致：

- **给节点改名** → 同位置的标签、兴趣点、同名房间轮廓自动改名
- **移动节点** → 标签和兴趣点跟着移动，相关步行路段长度自动重算
- **节点换楼层** → 关联的兴趣点、标签跟着换层

如果你手动把某个标签挪离了节点，它就不再联动，校验时会提示"失联"。

## 7. 校验（改完先查一遍）

点击工具栏 **「校验」**，右侧会生成报告，分两级：

| 级别 | 含义 | 示例 |
|---|---|---|
| **错误** | 数据不合法，必须修复 | 引用越界、自环、权重为负 |
| **警告** | 疑似问题，建议检查 | 孤立节点、跨层步行边、名字不一致 |

**点击任意一条报告可以自动跳转到问题所在位置。**

导出前如果还有"错误"，软件会提示你确认——建议先修复再导出。

---

## 8. 保存成果（导出）

1. 点击工具栏 **「导出数据」**
2. 确认或修改文件名（默认 `map-data.json`），保存到本地
3. 用导出的文件**覆盖项目中的 `data/map-data.json`**
4. 在项目根目录运行构建脚本，更新导航应用：

```bash
python scripts/build.py
```

之后重新打开（或刷新）导航应用 `index.html`，就能看到修改效果。

## 9. 常见问题

**Q：双击文件后浏览器显示乱码或空白？**
请换用 Chrome 或 Edge 打开。也可右键文件 → 打开方式 → 选择浏览器。

**Q：导入时提示"结构预检未通过"？**
说明所选文件不是本工具支持的地图数据格式。请确认选择的是 `data/map-data.json`（由本项目生成的文件），而不是其他 JSON 文件。

**Q：改错了怎么办？**
点工具栏「撤销」（快捷键 Ctrl+Z），可以连续撤销；「重做」（Ctrl+Y）可以恢复。

**Q：导出后导航应用没有变化？**
导出的文件需要**手动覆盖** `data/map-data.json`，并且运行 `python scripts/build.py` 重新构建。只导出不构建是不会生效的。

**Q：键盘快捷键不管用？**
如果当前光标在输入框里，快捷键会被输入法 / 文本输入占用。先点击一下画布空白处，再按快捷键。

**Q：画布上文字太小 / 太密？**
用滚轮放大，或在「图层」中隐藏暂时不需要的图层（如网格、标签）。

**Q：数据会上传到网上吗？**
不会。本工具完全在本机浏览器中运行，不发起任何网络请求。

## 10. 注意事项

1. **先备份再大改**。导出前建议先把原始 `map-data.json` 复制一份，以便对照或回退。
2. **不要用抓取脚本覆盖手工修改**。`data/build_data.py` 会从官方地图接口重新抓取数据并**整体覆盖** `map-data.json`，你手工修改的内容会全部丢失。修改应在抓取完成之后进行。
3. **导出后必须重新构建**。导出的 JSON 只是数据，导航页面（`index.html`）是打包好的单文件，必须运行 `python scripts/build.py` 才能生效。
4. **删除操作虽可撤销，但导出后就无法回退**。导出前请务必先点「校验」，并查看底部状态栏的"有未导出的修改"提示是否已消失。
5. **楼层编号（如 L1、B1）是引用关系的锚点**，修改楼层编号时相关引用会自动同步，但请尽量沿用原有命名习惯。
6. **坐标单位不是米**。地图坐标 10 个单位约等于 1 米（单位比例可在"元数据"中查看）。
