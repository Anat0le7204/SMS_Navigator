# 变更记录

## v2.2.1 — 2026-10-31

### 修复旋转闪烁 / 卡顿

- 根因：`#floorLayer` 的 `filter:drop-shadow` 在旋转时每帧重建离屏滤镜表面（实测 112–126 ms 长帧）；浮层 `backdrop-filter` 每帧重采样背景。
- 移除上述装饰性滤镜，浮层改为近乎不透明的浅色底，视觉基本不变。
- `containerSize()` 增加尺寸缓存与 `ResizeObserver` 失效，消除旋转期间每帧的强制布局。
- 标签 / 标记 / 比例尺 / 指针均改为「值变化才写 DOM」。
- 旋转缓动改为时间步长归一化，不同刷新率下速度一致；掉帧后自动追赶。
- 新增 `?nav=1`（直接进入导航）与 `?perf=1`（帧间隔写入标题栏）两个调试参数。
- 修复导航模式切换时因缓存导致的取景偏移。

## v2.1 — 2026-10-31

### 指南针 / 朝向旋转

- 新增 `src/js/15-compass.js`：能力检测、iOS 权限申请、绝对方向读取、EMA 平滑、rAF 旋转动画。
- 地图右上角新增“朝向”开关：支持时默认开启并记住选择；不支持时灰色禁用，点击弹出原因。
- 仅导航模式旋转：规划页保持正北；开始导航后地图旋转，使屏幕上方对应设备朝向。
- 旋转以可用区域中心为锚点，改造了 `applyView / fitBounds / screenToMap / zoomAt / 拖拽`，缩放与点选不漂移。
- 房间标签、起终点与换层标记反向旋转，始终保持正立。
- iOS 13+ 点击“授权”后请求方向权限；HTTPS/localhost 限制与状态说明见 `docs/COMPASS.md`。
- 新增调试参数 `?compass=sim&heading=90`、`?compass=unsupported`、`?compass=prompt`。

## v2.0 — 2026-10-31

### 架构

- 从单文件模板拆分为多文件开发：`src/index.html` + 4 个 CSS + 8 个 JS 模块 + 独立校徽资源。
- 新增 `scripts/build.py`：内联 CSS / JS / 校徽 / 地图数据，产出单文件离线网页。
- 新增 `README.md` 与 `docs/`（架构、数据、构建、变更）。
- 数据抽取与打包分离：`data/build_data.py` 只负责地图数据，`scripts/build.py` 只负责打包。

### 界面

- 品牌图标由文字“深中”替换为 **深圳中学校徽**（透明底 PNG，来源：深圳中学官网校徽页）。
- 摘要卡新增 **“开始导航”** 按钮。
- 新增全屏导航模式：
  - 顶部深绿色指令条：大方向图标、当前指令、距离 / 楼层 / 步数；
  - 底部路段卡：**当前路段矢量缩略图（图像）** + 剩余距离 / 时间 + 进度条 + **上一步 / 下一步**；
  - 地图自动切换楼层并按导航留白取景，当前路段高亮；
  - 支持键盘 `←` / `→` / `Esc`；
  - 最后一步按钮变为“完成”，点击结束导航。
- 导航缩略图按楼层裁剪、绘制房间多边形与路线，换层步骤自动纳入附近房间避免空白。
- 站点 favicon 同步替换为校徽。

### 优化

- 导航模式短步骤最小视野 70 m，避免 19 m 的步骤把地图放得过大。
- 剩余距离按步骤权重从总距离递减，末步显示“已到达”。
- 构建产物约 1.48 MB，仍为零外部依赖。

## v1.0 — 2026-10-30

- 首个可用版本：单文件 `index.html`。
- 19 层矢量平面图、1,874 个可搜索地点、Dijkstra 最短路。
